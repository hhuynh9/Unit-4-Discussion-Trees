### My Reflection

For this discussion, I learned more about how binary search trees organize data and why the order of insertion matters. 
I used employee ID numbers for my example because it is something that could actually be used in a workplace. 
The BST places smaller numbers on the left and larger numbers on the right, which makes searching easier when the tree 
is balanced.

The hardest part for me was understanding recursion, especially how the program continues searching through the left or
right child until it finds the number or reaches an empty node. Once I understood the base cases, the insertion and 
search methods started making more sense.

I also learned how in-order traversal returns the numbers in sorted order. That was helpful because I could check 
whether my tree was working correctly.

Compared to searching through a regular list one item at a time, a balanced BST can be faster because it eliminates 
part of the search space with each comparison. However, if values are inserted in sorted order, the tree can become 
unbalanced and lose that advantage.

This assignment helped me understand how trees can organize and search information more efficiently.
